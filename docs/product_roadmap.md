# BehaviorGraph — Product Roadmap

## Phase 0 / MVP (this repo)

- Synthetic event dataset + taxonomy
- Activation funnel
- Retention cohorts
- Path / journey graph (NetworkX)
- Segments + friction points
- Product opportunity memo
- Next.js cockpit + FastAPI analytics API

## Phase 2

- Orphan event detection
- Sequence analysis beyond pairwise transitions
- Behavioral cohorts (not only calendar cohorts)
- Activation drop alerts
- Instrumentation recommendations

## Phase 3

- Minimal first-party SDK
- Near-real-time ingest
- Experiment tags
- Demo app integration
- Product Q&A assistant over the event graph

## Explicit non-goals

- Do not become a generic metrics dashboard
- Do not compete feature-for-feature with Mixpanel
- Do not ship production tracking in the MVP
